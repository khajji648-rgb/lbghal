# 🎯 لعبة تحدي لوحة الرشق | Target Cheek Challenge (نسخة Android & Web)

لعبة كرتونية تفاعلية ثلاثية الأبعاد خفيفة وممتعة، مستوحاة من أسلوب ديزني/بيكسار الكرتوني مع مؤثرات صوتية وفيزيائية فكاهية!

![Game Preview](assets/cover.jpg)

---

## 📱 خيارات الحصول على التطبيق كـ APK والتثبيت على أندرويد:

### 1️⃣ الخيار الأول: التثبيت الفوري كـ تطبيق أصلي (PWA / WebAPK) - بدون تحميل أدوات
اللعبة مجهزة بالكامل بتقنية **Progressive Web App**:
- عند فتح رابط اللعبة من أي هاتف أندرويد عبر متصفح **Chrome** أو **Samsung Internet**.
- سيظهر زر باللون الأخضر: **"📲 تثبيت اللعبة على هاتفك"** (أو اضغط على خيارات المتصفح واختر **"تثبيت التطبيق"** / **"إضافة إلى الشاشة الرئيسية"**).
- سيقوم نظام Android بإنشاء أيقونة اللعبة في قائمة التطبيقات وتعمل بملء الشاشة تماماً مثل أي ملف APK رسمي وبدون اتصال بالإنترنت (Offline).

---

### 2️⃣ الخيار الثاني: تحويل الملف إلى APK جاهز عبر الإنترنت (في ثوانٍ)
لقد قمنا بتجهيز حزمة الويب الكاملة مع أيقونات التطبيق وملف `manifest.json`:
- **الملف الجاهز للرفع:** [TargetCheekGame-PWA-Web.zip](TargetCheekGame-PWA-Web.zip)
- توجه إلى أداة تحويل الويب إلى APK مجاناً مثل:
  - **[PWABuilder](https://www.pwabuilder.com)** (أداة رسمية وسريعة جداً)
  - أو **[Web2Apk](https://www.web2apk.com)**
- ارفع الملف أو الرابط وستحصل على ملف **`.apk`** موقع وجاهز للتثبيت بنقرة واحدة.

---

### 3️⃣ الخيار الثالث: مشروع Android Studio الكامل (جاهز للبناء)
تم تجهيز مشروع أندرويد نيتف كامل (Native Android Studio Project) مدمج به الـ WebView بكامل ملفات اللعبة:
- **المجلد:** [android/](android/)
- **الملف المضغوط:** [TargetCheekGame-Android-Project.zip](TargetCheekGame-Android-Project.zip)
- **خطوات الاستخراج:**
  1. افتح مجلد `android` داخل **Android Studio**.
  2. اضغط من القائمة العلوية على: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
  3. سيتم استخراج ملف الـ APK النهائي في ثوانٍ داخل مجلد:
     `android/app/build/outputs/apk/debug/app-debug.apk`.

---

### 4️⃣ الخيار الرابع: البناء السحابي التلقائي (GitHub Actions)
تم إعداد ملف العمل التلقائي `.github/workflows/build-apk.yml`. بمجرد رفع المشروع إلى مستودع GitHub، سيقوم خادم السحابة ببناء ملف الـ APK تلقائياً وتقديمه للتحميل المباشر.

---

## 💻 طريقة تشغيل اللعبة على الكمبيوتر
- انقر نقراً مزدوجاً فوق ملف **`start.bat`** لفتحها على: `http://localhost:3000`.
